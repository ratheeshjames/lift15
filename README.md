# Lift 15 — PWA v2

A beginner-friendly 15-minute dumbbell workout PWA.

## Added in v2
- Built-in exercise library with beginner instructions
- Starting position, 3-step movement guide, breathing, common mistakes, tips and safety notes
- "How to do it" button directly on the workout timer
- Tap any exercise in today's routine to learn it
- Searchable exercise library
- Tap any day in the weekly schedule to preview that day's workout
- Preview exercises without starting the timer
- First-launch beginner onboarding
- Offline-friendly exercise information
- Existing timer, sound, voice, vibration, wake lock, weights, history and progress retained

## Install/update
Serve the folder from an HTTPS host. If an older Lift 15 installation is already installed, open the site once while online so the v2 service worker can update the cached app, then relaunch it.
